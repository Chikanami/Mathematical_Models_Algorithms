# 多个实体的交互迭代算法原型

一个通用的离散系统建模框架，用统一的 **"实体 + 交互规则 + 参数"** 结构描述不同问题。

## 核心公式

$$g\big(f_1(W_1),\ f_2(W_2),\ \dots,\ f_n(W_n),\ h(M),\ P\big)$$

| 组成部分 | 职责 |
|----------|------|
| $f_n(W_n)$ | 描述第 $n$ 个**实体**及其初始状态 |
| $h(M)$ | 描述所有实体之间的**交互规则**，接收当前状态，返回后继状态 |
| $P$ | **参数集**：定义迭代规则、迭代次数、终止条件等 |
| $g(\cdot)$ | 主驱动函数，组装上述三者并执行迭代 |

实体数量 $n$ 不固定——可以是两个（DICE、Mandelbrot），也可以是任意多个（WaterSort）。交互规则 $h$ 是外置于实体的系统级函数，作用于所有实体的当前状态并产生下一状态。

---

## 示例

### 1. DICE — 字符串映射

最简形式：两个实体通过取模映射交互，每轮迭代后实体自身发生变异。

| 框架组件 | 对应实现 |
|----------|----------|
| $f_1(W_1)$ | 整数列表 `[3,1,4,1,5,9,...]`（π 的数字） |
| $f_2(W_2)$ | 字符表（26 字母 + 10 数字 + 2 标点，共 38 个字符） |
| $h$ | 对 $W_1$ 中每个整数取模查表，拼出字符串 |
| $P$ | `iterations=5`；`mutate_A`：每轮对整数加轮次值；`mutate_B`：对字符表做循环移位 |

```bash
python DICE.py
```

输出 5 轮演化字符串，每轮的映射结果因实体变异而不同。

---

### 2. Mandelbrot — 曼德勃罗集生成

将经典分形迭代 $z_{n+1} = z_n^2 + c$ 编码为双实体交互。

| 框架组件 | 对应实现 |
|----------|----------|
| $f_1(W_1)$ | $z \mapsto z^2$（迭代变量） |
| $f_2(W_2)$ | $c \mapsto c$（复平面上的点） |
| $h$ | $a + b$，即 $z^2 + c$ |
| $P$ | `max_iter=256`，逃逸阈值 $|z|>2$ |

`g()` 对每个复平面点执行迭代并返回逃逸时间，`generate_mandelbrot()` 遍历网格生成完整分形图像。

```bash
python Mandelbrot.py
```

弹出 matplotlib 窗口，渲染曼德勃罗集的逃逸时间着色图。

---

### 3. WaterSort — 水排序谜题状态空间搜索

最复杂的形式：每个试管是一个独立实体，交互规则枚举所有合法倾倒操作，驱动函数以 BFS 搜索完整状态空间。

| 框架组件 | 对应实现 |
|----------|----------|
| $f_1 \dots f_n$ | 从 JSON 文件动态生成，每个试管为一个实体 |
| $h$ | 枚举所有合法的 (源管, 目标管) 倾倒，返回全部后继状态 |
| $P$ | 容积 `Vol`、规范化函数（消除置换对称）、目标检测、状态上限 |
| $g$ | BFS 引擎，枚举全部可达状态，构建状态空间图 |

附加能力：
- **Tarjan SCC 分析**：识别状态空间中的强连通分量
- **单轨迹模式**：按策略（`first_valid` / `random` / `longest`）逐步演示演化路径
- **HTML 交互式可视化**：生成相图，按节点类别（初始态 / 解 / 死胡同 / 普通态）着色

```bash
# BFS 枚举 + 控制台输出
python WaterSort_EntityModel.py WaterTest.json

# 生成 HTML 相图
python WaterSort_EntityModel.py WaterTest.json --html

# 单条轨迹模式
python WaterSort_EntityModel.py WaterTest.json --trajectory longest
```

## 三个示例的对比

| | DICE | Mandelbrot | WaterSort |
|---|---|---|---|
| 实体数 | 2 | 2 | $n$（动态） |
| 实体类型 | 整数列表 + 字符表 | 复数 $z$ + 复数 $c$ | 试管（元组） |
| 交互规则 | 取模映射 | 加法（$z^2+c$） | 倾倒操作枚举 |
| 迭代方式 | 固定轮次 + 变异 | 逃逸时间判定 | BFS 状态空间遍历 |
| 输出 | 字符串序列 | 分形图像 | 状态图 / 轨迹 |
| 复杂度 | 低 | 中 | 高 |

## 可应用的学术领域

| 领域 | 适用方向 |
|------|----------|
| 离散动力系统 | 作为低维离散映射的交互范例，研究状态空间的演化与周期性 |
| 符号动力学 | 输出字符串可视为符号序列，分析其熵、复杂度、遍历性 |
| 元胞自动机 / 复杂系统 | 双实体可看作两个"细胞"或"层"，规则为取模映射 + 循环移位 |
| 演化计算 / 遗传算法 | 变异规则（加轮次、循环移位）是极简的突变算子，可作为算法原型测试适应度函数 |
| 教育数据科学 | 用于演示"模型"与"数据生成过程"的基本概念，适合教学 |
| 计算语言学 | 将实体 B 视为字母表，映射规则可模拟简单的置换密码或生成类语言序列 |
| 密码学与伪随机数 | 弱随机性发生器原型，可作为随机性测试的基准源，经过精密调试可作为实用性广播加密协议使用 |

## 可应用的商业领域

| 领域 | 适用方向 |
|------|----------|
| 合成数据生成 | 快速生成具有"演化结构"的字符串序列，用于测试数据处理管道或隐私保护模拟 |
| 数据增强 | 在文本或序列分类任务中，用简单映射生成变体样本，提高模型鲁棒性（尤其当原始数据稀疏时） |
| 异常检测基准 | 正常演化序列是确定的；若有突变规则变化，可被检测，从而作为异常检测算法的测试用例 |
| 客户行为模拟 | 将客户状态编码为整数列表，输出为行为标签序列，模拟不同策略下的客户旅程演化 |
| 轻量级 A/B 测试辅助 | 定义两种变异规则（不同 P），生成对照组与实验组的输出轨迹，观察长期差异 |
| 教育科技 | 作为编程作业或数据科学入门实验：让学生修改实体、映射规则，观察输出变化，理解"模型"与"参数"的关系 |
| 游戏玩法生成 | 基于玩家输入（实体 A）和游戏词典（实体 B），动态生成下一关的对话或谜题序列 |
