该模型实现了一类 **离散状态空间上的双映射迭代动力系统**，形式化描述为：

g(f(W),κ(O),h(m),P)：

>函数f(W)与κ(O)描述了两个任意实体；
>
>函数h(m)描述了两个实体之间的交互规则；
>
>参数P描述了是否进行迭代、迭代规则与迭代次数。

>该函数完整描述了离散状态空间上的双映射迭代动力系统。

示例代码1.py中，该模型展示了对于以实体A（索引列表）、实体B（元字符集合）以及函数h（交互规则）为广播密文，以参数P为密码本的广播加密协议。

同时该示例代码亦极简的迭代动力系统，生成伪随机序列。
